## 资源命名

接口路径应该表达资源，而不是表达动作。比如使用 `/api/conversations/{id}/messages`，比 `/api/sendMessage` 更容易扩展。

## 统一响应

统一响应结构能让调用方更容易处理错误：

```json
{
  "code": "OK",
  "message": "success",
  "data": {}
}
```

## 幂等性

创建订单、发起任务、执行工具调用这类接口要考虑幂等性。尤其在 AI 应用中，重试可能导致重复执行外部操作。

## 小结

接口设计不是格式问题，而是系统边界问题。边界清晰，系统才容易维护。
