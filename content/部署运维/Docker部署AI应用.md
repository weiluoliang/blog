## 为什么使用 Docker

AI 应用通常依赖模型 SDK、数据库、缓存和任务队列。Docker 可以把运行环境固化下来，让本地、测试和生产环境更接近。

## 基础镜像

后端服务建议选择体积较小、维护活跃的基础镜像。Node、Java、Python 项目都应该明确运行时版本，避免“本地能跑，线上不行”。

## 环境变量

API Key、数据库连接串和模型配置不要写死在镜像里。使用环境变量或密钥管理服务注入配置。

## 小结

Docker 不是部署的终点，而是稳定交付的起点。后续还需要配合 CI/CD、日志、监控和回滚策略。
